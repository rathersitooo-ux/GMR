# GAMEROAD

## 遊ぶ

**[▶ GAMEROAD 最新公開版をブラウザで遊ぶ](https://gameroad-browser-r5.pages.dev/)**

このGitHubリポジトリを、GAMEROADの公開入口として使えます。上の「遊ぶ」リンクは固定です。

ゲーム本体の正式な公開版は、`main` に取り込まれた公開可能な Browser build から自動配布されます。開発中の未merge PRは公開版には含めません。

- **公開入口:** このREADME
- **最新版プレイ:** 上の固定「遊ぶ」リンク
- **ソース／変更履歴:** このGitHubリポジトリ
- **公開版の基準:** `main` に統合済みで公開可能な Browser build

> 目的: 新しいURLを毎回探したり、ChatGPTへ最新版リンクを聞いたりせず、このGitHubページから常に現在の公開版へ到達できること。
